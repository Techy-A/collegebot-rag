# ChromaDB was replaced with FAISS because chroma-hnswlib
# requires Microsoft C++ Build Tools to compile on Windows,
# which is an unnecessary barrier for a development setup.
# FAISS ships pre-built Windows wheels and requires no compiler.
#
# ALWAYS install inside a clean virtual environment:
#   python -m venv collegebot_env
#   collegebot_env\Scripts\activate
#   pip install -r requirements.txt
#
# Verify after install:
#   pip show langchain   ->  must show Version: 0.2.16
#   pip show faiss-cpu   ->  must show Version: 1.8.0
